This repository contains projects from the book "Learn Go with Pocket-Sized Projects" by Aliénor Latour, Donia Chaiehloudj, and Pascal Bertrand.

The authors explain a large portion of each project's code; however, they intentionally leave parts unfinished to give readers the opportunity to write code on their own.

Each project subdirectory includes a corresponding README.md specifying which code chunks were written by me.
